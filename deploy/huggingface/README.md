# TacketPay — live demo

**Every rupee here is fake.** No bank, card or UPI network is connected; receipts are watermarked
"DEMO MONEY · NOT REAL". Never enter a real PIN or bank detail.

**Demo data resets periodically:** this Space keeps no persistent storage, so accounts, balances and
payments are wiped whenever it restarts (after a rebuild, or when it wakes from sleep).

To try a payment, sign in as **Diya** (mobile 98765 43210, demo PIN 1234) and pay **Aarush**
(91234 56789, PIN 4321), or create your own account with a made-up mobile number (other visitors
can see the names on this shared demo).
